# Звук взрывов и стрельбы

Взрывы MTS воспроизводятся в мировой точке взрыва. Тридцать стереосэмплов
взрывов, ракет и суббоеприпасов сведены в mono для позиционирования OpenAL.
Громкость по расстоянию по-прежнему рассчитывается пресетами MTS, поэтому
второе автоматическое затухание не добавляется. В настройках Minecraft для
лучшего определения направления можно включить направленный звук (HRTF).

Дальность выстрела задаётся полем `SoundRadius` в JSON оружия или техники.
Для многослойных звуков Squad сервер вычисляет радиус рассылки в блоках как
`ceil(6.4 × SoundRadius)` и передаёт его клиенту для затухания всех слоёв.
При значении 4 звук достигает 26 блоков, при 160 — 1024 блоков.

Сетевой протокол версии 3 требует обновить мод на сервере и у игроков.
